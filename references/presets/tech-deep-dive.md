# 技术深度讲解 (Tech Deep Dive) - 预处理模板

## 重点保留要素
- **技术名词与缩写**（即使很生僻也要保留原词，不要乱翻译）。
- **系统架构描述**（层级关系、模块划分、数据流向）。
- **代码片段与配置参数**（保留核心逻辑和关键参数，剔除大段的无关 import 和 boilerplate）。
- **性能数据与基准测试**（耗时、内存、并发量等绝对数值及对比）。
- **报错信息与调试日志**（如果原文用来举例排障，保留具有代表性的几行日志）。

## 重点提炼方向 (结构补全用)
- 将大段关于"A 方案与 B 方案选型"的文字，提炼为**优缺点对比表格**。
- 将冗长的"第一步安装，第二步配置..."文字，提炼为**有序流程列表**。

## 适用场景判断
当原文包含大量代码块、架构图说明、技术选型探讨、性能调优经验时，命中本模板。
