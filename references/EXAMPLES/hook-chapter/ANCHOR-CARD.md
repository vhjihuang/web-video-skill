# 钩子型开场 章节 Anchor Card

**特征**：抛 N 张可疑图 / 反例 / 截图制造悬念，最后切大字 hero takeover 揭示主题。

## 结构骨架

| Step | 做什么 | 焦点 |
|------|--------|------|
| S0 | N 张 ghost 占位卡（虚线/暗态）抛悬念 | 让观众疑惑"这是什么" |
| S1 | 第 1 张图独占视觉露出（~70% 屏幕） | 观众盯着图想"这是真的吗" |
| S2 | 第 2 张图独占视觉露出，继续累积疑问 | 每张图独占一步，绝不同时上 |
| S3 | 所有图缩入侧栏 + hero 巨字 takeover + 钩子收束 | 揭示主题，引下一章 |

## 字号关系
hero: ~144px / N: ~28px / cue: ~40px

## 动画基调
brush-stroke 划掉 + 印章砸下，newsroom 干净节奏，不过度装饰。

## ⚠️ 最容易犯的错误
N 张图 stagger 同时上——口播逐个念但画面一次性全露，观众扫一眼看完 = PPT 直觉。
