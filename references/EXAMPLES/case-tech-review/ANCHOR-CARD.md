# 科技测评类 案例 Anchor Card

**特征**：AI/产品实测对比 → 7 章递进结构（钩子→优点→场景→进阶→收束），双源原则：口播说一件事画面挂多件事。

## 结构骨架

| Step | 做什么 | 焦点 |
|------|--------|------|
| S0 | 钩子开场：排行榜/悬念截图/pull-quote 慢镜入场 | 制造"值得看"的疑问 |
| S1 | 优点列举：N 个方向逐个揭示，每项独占视觉、数据角标挂满 | 证明"强在哪" |
| S2 | 场景展示：在哪用/怎么用，实操画面 + before/after 对照 | 证明"哪能用" |
| S3 | 进阶/收束：高阶玩法 + 总结收尾 | 证明"怎么用好"，防止虎头蛇尾 |

## 字号关系
hero: ~120px / 数据角标 mono cue: ~28px / 副标: ~36px

## 动画基调
midnight-press 暗色印刷气质：慢镜式聚焦、暖橙 accent、克制有重量，禁装饰性连续动效 / emoji。

## ⚠️ 最容易犯的错误
照抄历史版本的动画参数（如"blur clear 1.5s ease-out"），而不是按本项目主题气质重新选型。
